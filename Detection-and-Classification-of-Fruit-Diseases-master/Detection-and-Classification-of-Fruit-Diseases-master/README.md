**# 🍎 Detection and Classification of Fruit Diseases Using Image Processing and Machine Learning**



This project is a GUI-based application built in Python that uses image processing and machine learning techniques to detect and classify fruit diseases from images.



**## 📌 Features**

\- Load fruit images from file system

\- Image preprocessing (resizing, filtering)

\- Feature extraction using image processing techniques

\- Disease classification using ML algorithms

\- GUI built with Tkinter (or PyQt)

\- Trained models included for accurate predictions



**## 🛠 Technologies Used**

\- Python 3.x

\- OpenCV

\- scikit-learn

\- NumPy, Pandas

\- Tkinter (or mention PyQt if used)

\- Machine Learning (SVM, KNN, etc.)



**## 🚀 How to Run the Project**



1\. **Clone the repository:**

 

git clone https://github.com/Krishna23-IT/Detection-and-Classification-of-Fruit-Diseases.git

cd Detection-and-Classification-of-Fruit-Diseases



**Install dependencies:**

pip install -r requirements.txt



**Run the app:**

python app.py

(Replace app.py with your actual main file name if different.)





**📂 Dataset**

* Trained on a dataset of fruit images with various diseases.



* You can expand the dataset or retrain the model if needed.
